##<a id='nsxt30-prereqs'></a> Prerequisites for Installing VMware NSX

To perform a new installation of VMware NSX for {{  vars.product }}, complete the following steps in the order presented.

1. Read the [Release Notes](./release-notes.html) for the target TKGI version you are installing and verify NSX v3 support.

1. Read the topics in the [Preparing to Install {{  vars.product }} on vSphere with VMware NSX](./vsphere-nsxt-index-prepare.html) section of the documentation.
